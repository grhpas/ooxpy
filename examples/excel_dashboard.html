Tutorial 8: Tables, conditional formatting, notes and print setup

Excel tables with totals, conditional formats, comments, hyperlinks, shared strings, print setup, hidden and protected sheets. Script: examples/excel_dashboard.py

Excel tables

from oox import SpreadsheetDocument
from oox.spreadsheet import Formula

book = SpreadsheetDocument.new("Sales")
book.append_row("Sales", ["Region", "Target", "Actual"])
for row in [("North", 100, 120), ("South", 100, 30), ("West", 80, 84)]:
    book.append_row("Sales", list(row))
book.add_table("Sales", "A1:C4", name="Sales2026",
               totals={"Region": "Total", "Target": "sum", "Actual": "sum"})
book.set_value("Sales", "E1", Formula("SUM(Sales2026[Actual])", 234))
print(book.tables("Sales")[0]["ref"], book.value("Sales", "C5"))
A1:C5 234

The first row is the header. The totals row uses SUBTOTAL formulas, and oox stores their results, so readers that don't calculate see the numbers too. Formula(..., cached) does the same for your own formulas.

Conditional formatting

book.conditional_format("Sales", "C2:C4", "formula", formula="$C2<$B2",
                        style={"fill": "FFC7CE", "color": "9C0006"})
book.conditional_format("Sales", "C2:C4", "data_bar", color="638EC6")
book.conditional_format("Sales", "A2:A4", "text", text="South", style={"bold": True})
print([r["type"] for r in book.conditional_formats("Sales")])
['expression', 'dataBar', 'containsText']

Rules: cell (>, between ...), formula, color_scale, data_bar, icon_set, top/bottom, above_average, duplicates/unique, text, blanks. Formulas are relative to the range's top-left cell, as in Excel.

Comments and hyperlinks

book.add_sheet("Lookup")
book.add_comment("Sales", "C3", "Storm damage closed two stores.", author="Ada")
book.add_hyperlink("Sales", "E3", "https://ecma-international.org/", text="About OOXML")
book.add_hyperlink("Sales", "E4", "#Lookup!A1", text="Region codes")
print(book.comments("Sales"), book.hyperlinks("Sales")["E4"])
{'C3': ('Ada', 'Storm damage closed two stores.')} #Lookup!A1

Print setup and sheet options

book.page_setup("Sales", orientation="landscape", paper="A4", fit_width=1,
                repeat_rows="1:1", footer={"right": "Page {page} of {pages}"})
book.sheet_options("Sales", tab_color="2F5496")
book.sheet_options("Lookup", hidden=True)
book.protect_sheet("Sales", password="secret", allow=("sort",))
book.share_strings()
print(book.sheet_options_info("Lookup")["hidden"], book.page_setup_info("Sales")["footer"])
book.save("dashboard.xlsx")
True {'right': 'Page {page} of {pages}'}

Header and footer text takes {page}, {pages}, {date}, {sheet} and {file}. Sheet protection uses Excel's legacy password hash: it stops casual edits, not a determined reader. share_strings() stores text the way Excel does: one shared copy of each distinct string.
