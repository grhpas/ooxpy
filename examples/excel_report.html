Tutorial 7: Formatted Excel reports

Cell styles, number formats, dates, column widths, frozen panes, filters, names and drop-downs. Script: examples/excel_report.py

Styles

cell_style returns an index you pass as style=. Equal styles share one entry in the workbook's stylesheet, however many cells use them:

from oox import SpreadsheetDocument

book = SpreadsheetDocument.new("Orders")
header = book.cell_style(bold=True, color="FFFFFF", fill="2F5496", align="center")
money = book.cell_style(number_format="#,##0.00;[Red]-#,##0.00")
book.append_row("Orders", ["Customer", "Amount"], style=header)
book.set_value("Orders", "A2", "Acme")
book.set_value("Orders", "B2", 1250, style=money)
book.set_value("Orders", "B3", -120, style={"number_format": "#,##0.00;[Red]-#,##0.00"})
print(book.cell_style(bold=True, fill="2F5496", color="FFFFFF", align="center") == header)
print(book.display_text("Orders", "B2"), book.display_text("Orders", "B3"))
True
1,250.00 -120.00

display_text gives the text Excel shows, with the number format applied. The Office check compares it with Excel's own Range.Text.

Dates

import datetime as dt

book.set_value("Orders", "C2", dt.date(2026, 11, 14))            # gets a date format
book.set_value("Orders", "C3", dt.datetime(2026, 11, 14, 9, 30),
               style={"number_format": "d mmm yyyy hh:mm"})
print(book.value("Orders", "C2"), "|", book.display_text("Orders", "C3"))
2026-11-14 00:00:00 | 14 Nov 2026 09:30

Excel stores dates as numbers with a date format. oox adds the format when you write a date, and value() gives a datetime back for date-formatted cells, in any workbook.

Layout

book.set_column_width("Orders", "A", 22)        # characters, as Excel shows them
book.set_column_width("Orders", "B:C", 14)
book.set_frozen_panes("Orders", "A2")                # keep the header row visible
book.auto_filter("Orders", "A1:C3")
book.merge_cells("Orders", "A5:C5")
book.define_name("Amounts", "Orders", "B2:B3")
book.add_validation("Orders", "D2:D3", values=["Open", "Paid"])
print(book.column_width("Orders", "A"), book.frozen_panes("Orders"), book.defined_names()["Amounts"])
book.save("orders.xlsx")
22.0 A2 Orders!$B$2:$B$3

Each setting has a reader that works on workbooks from Excel and LibreOffice too: column_width, row_height, merged_cells, frozen_panes, auto_filter_range, defined_names, validations, cell_format.
