Tutorial 1: Your first Word document

Factories, schema order, early errors. Script: examples/hello.py

The idea

oox gives you one factory function per OOXML element, generated from the schema, the same way odfpy does for ODF. You build the XML tree directly and oox checks it as you go. A Word paragraph is w:p, which holds runs (w:r), which hold text (w:t):

from oox import WordprocessingDocument
from oox.ns import w

doc = WordprocessingDocument.new()
doc.body.add(
    w.P(w.R(w.T("Hello, OOXML"))),
    w.P(w.R(w.RPr(w.B()), w.T("Bold")), w.R(w.T(" and normal"))),
)
doc.save("hello.docx")

w.RPr holds run properties: w.B() is bold, w.I() italic, w.Sz(val=28) is the size in half-points (14 pt).

Styles, headings and properties

A new document comes set up the way Word sets one up: styles (Normal, Title, Heading 1–3, List Paragraph, Table Grid…), the Office theme and an A4 page (new(page="Letter"), landscape=True). Styles can be referred to by name:

report = WordprocessingDocument.new()
report.add_heading("Quarterly report", 0)        # 0 = Title
report.add_heading("Introduction", 1)
report.add_paragraph("Body text in the Normal style.")
report.add_paragraph("An indented item", style="List Paragraph")
report.properties.title = "Quarterly report"     # File > Properties
report.properties.creator = "Ada"
report.save("report.docx")
print(report.style_id("Heading 1"))
Heading1

Lists

steps = report.new_list("decimal")        # also "bullet" and "legal" (1. 1.1. 1.1.1.)
steps.add("Collect the data")
steps.add("by region", level=1)
steps.add("Write the summary")
again = steps.restart()                    # same format, starts again at 1
again.add("New list")
print([item.label for item in report.list_labels()])
report.save("report.docx")
['1.', 'a.', '2.', '1.']

list_labels() also works on documents from Word or LibreOffice: it computes the number Word displays for each list paragraph. Each item also carries the paragraph, its level, the list's ids, the number format and the label's font.

WordprocessingDocument.new(minimal=True) gives the smallest valid package instead, with no styles; Word fills in its own defaults.

Order is handled for you

Word rejects properties in the wrong order ("unreadable content"). oox inserts every child at its schema position, so you can write them in any order:

p = w.P(w.PPr(w.Jc(val="center"), w.Spacing(after=240), w.PStyle(val="Title")))
print([child.tag_name for child in p[0]])
['w:pStyle', 'w:spacing', 'w:jc']

Mistakes fail early

import textwrap
from oox import OoxValidationError

for attempt in (lambda: w.Jc(val="middle"),      # not an allowed value
                lambda: w.P(w.Tbl()),            # a table can't go inside a paragraph
                lambda: w.Spacing(aftr=240)):    # typo
    try:
        attempt()
    except OoxValidationError as e:
        print(type(e).__name__, "-", textwrap.shorten(str(e), 72))
InvalidAttributeValue - w:val='middle' is not one of: left, start, center, right, end, [...]
InvalidChild - <w:tbl> is not allowed in <w:p>; allowed: m:acc, m:bar, [...]
InvalidAttribute - w:spacing has no attribute 'aftr'; did you mean after, w_after?

Use with oox.lenient(): to turn the checks off, e.g. while repairing odd files.

Attributes

Attributes are keyword arguments named after the attribute's local name. Python values are converted for you:

You writeXML
w.Spacing(after=240)w:after="240"
w.B(val=False)w:val="0"
w.FooterReference(type="default", r_id="rId7")r:id: add the prefix when a name is ambiguous
w.Spacing(**{"w:line": 360})any attribute by its prefixed name

Text helpers and checking

from oox import teletype

p = w.P()
teletype.addTextToElement(p, "Name:\tAda\nsecond line")   # \t -> w:tab, \n -> w:br
doc.body.add(p)
print(teletype.extractText(p))
print(doc.document.validate())     # [] means no problems found
doc.save("hello.docx")
