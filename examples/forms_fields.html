Tutorial 6: Formatting, fields and forms

Run and paragraph formatting, custom styles, captions and cross-references, properties, content controls, more image formats. Script: examples/forms_fields.py

Formatting and styles

from oox import WordprocessingDocument

doc = WordprocessingDocument.new()
doc.add_style("Note", italic=True, color="595959", indent_left=36, space_before=6)
p = doc.add_paragraph("", style="Note")
warning = doc.add_run(p, "Warning: ", bold=True, color="C00000")
doc.add_run(p, "check the figures.", size=12, font="Georgia")
doc.format_paragraph(p, align="center", space_after=12)
fmt = doc.formatting()
para, run = fmt.paragraph(p), fmt.run(warning)
print(run.bold, run.italic, run.color, para.style, para.space_before, para.indent_left)
True True C00000 Note 6.0 36.0

Sizes, spacing and indents are in points (36 pt = ½ inch), or a length from oox.units (Cm(1)). doc.formatting() works out what Word shows: document defaults, table styles, the style chain, numbering, character styles and direct formatting, with theme fonts looked up. It works on any document, and it reports values in the forms the writers take.

Properties

doc.properties.title = "Quarterly figures"
doc.extended_properties.company = "Example Ltd"
doc.custom_properties["Quarter"] = "Q3"
doc.custom_properties["Approved"] = True
print(doc.custom_properties.as_dict())
{'Quarter': 'Q3', 'Approved': True}

The same three work for workbooks and decks.

Captions, cross-references and fields

cap = doc.add_caption("Revenue by region", label="Table")
doc.add_table([["Region", "Q3"], ["North", 135]], header_rows=1)
q = doc.add_paragraph("See ")
doc.add_cross_reference(q, cap)                       # "Table 1"
doc.add_run(q, ", ")
doc.add_cross_reference(q, cap, what="position")      # "above"
doc.add_run(q, " - ")
doc.add_field(q, 'DOCPROPERTY "Company"')
first = doc.add_caption("Inserted earlier", label="Table", before=cap.paragraph)
print(cap.number, [f.result for f in doc.fields() if f.name in ("REF", "DOCPROPERTY")])
2 ['Table 2', 'above', 'Example Ltd']

Word only recomputes fields on F9 or printing, so oox writes correct results: captions renumber when one is inserted, and references follow. doc.update_fields() recomputes everything that doesn't need page layout, in any document: sequence numbers, references, document properties and dates. Page numbers in references are estimates until Word updates them.

Forms: content controls

import datetime as dt

form = WordprocessingDocument.new()
form.add_text_control(form.add_paragraph("Name: "), tag="name", placeholder="Your name")
form.add_dropdown(form.add_paragraph("Type: "), tag="type", items=["Annual", "Sick"])
form.add_date_control(form.add_paragraph("From: "), tag="from", fmt="d MMMM yyyy")
form.add_checkbox(form.add_paragraph("Informed: "), tag="informed")
form.fill_controls({"name": "Ada", "type": "Sick", "from": dt.date(2026, 12, 21),
                    "informed": True})
print([(c.tag, c.value) for c in form.content_controls()])
[('name', 'Ada'), ('type', 'Sick'), ('from', '21 December 2026'), ('informed', True)]

A template with controls is filled by tag, so the layout stays the template author's. Check boxes are an Office 2010 feature; Word 2007 shows the ☐/☒ character instead.

More image formats

doc.add_picture("chart.png", fallback=None)            # PNG, JPEG, GIF, BMP, TIFF, EMF, WMF
svg = b'<svg xmlns="http://www.w3.org/2000/svg" width="160" height="80"/>'
doc.add_picture(svg, fallback="chart.png")              # SVG needs a raster fallback
doc.save("report.docx")

Office shows SVG from 2016 on; older versions show the fallback picture. Vector formats (EMF, WMF, SVG) get their physical size from the file.
