Tutorial 3: Excel, PowerPoint and pictures

One core, three formats. Script: examples/showcase.py (writes all three). The snippets use chart.png; any PNG, JPEG, GIF or BMP will do.

Sizes

Drawings are measured in EMU (914,400 per inch). Use the helpers from oox.units: Inches, Cm, Mm, Pt, Px. When placing a picture, give one dimension and the other follows the aspect ratio; give none for the picture's natural size (from its DPI).

Excel

from oox import SpreadsheetDocument
from oox.spreadsheet import Formula
from oox.units import Cm, Inches

book = SpreadsheetDocument.new("Sales")             # starts with one sheet
book.append_row("Sales", ["Region", "Units", "Price", "Revenue"])
book.append_row("Sales", ["North", 120, 9.5, Formula("B2*C2")])
book.append_row("Sales", ["South", 95, 11.0, Formula("B3*C3")])
book.append_row("Sales", ["Total", Formula("SUM(B2:B3)"), None, Formula("SUM(D2:D3)")])
book.add_sheet("Notes")
book.append_row("Notes", ["Figures are provisional"])
book.add_picture("Sales", "chart.png", anchor="F2", width=Cm(10))
book.save("sales.xlsx")

PowerPoint

A new deck already has a master, a theme and three layouts: "Title Slide", "Title and Content" and "Blank". Use placeholders for layout-styled text, and text boxes for free placement:

from oox import PresentationDocument

deck = PresentationDocument.new()                    # 16:9; pass width/height for others
title = deck.add_slide("Title Slide")
deck.set_placeholder_text(title, "title", "Regional sales")
deck.set_placeholder_text(title, "subtitle", "Q3 review")

slide = deck.add_slide()                              # "Blank"
deck.add_textbox(slide, Inches(0.7), Inches(0.5), Inches(12), Inches(1),
                 "Units by region", size=36, bold=True, color="1F3864")
deck.add_picture(slide, "chart.png", Inches(1), Inches(1.8), width=Inches(6))
deck.save("sales.pptx")

Word

from oox import WordprocessingDocument
from oox.ns import w

doc = WordprocessingDocument.new()
doc.body.add(w.P(w.R(w.T("Units by region:"))))
doc.add_picture("chart.png", width=Cm(14), descr="Bar chart")   # in a new paragraph
p = w.P(w.R(w.T("Inline icon: ")))
doc.body.add(p)
doc.add_picture("chart.png", height=Cm(0.5), paragraph=p)        # inside a sentence
doc.save("sales.docx")

The same image used twice is stored once. The file's dimensions and resolution are read from its header, so no imaging library is needed.
