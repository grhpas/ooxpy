oox tutorials

Short, runnable introductions. Each sits next to a script in examples/. The full documentation comes later.

  1. Your first Word document: factories, schema order, early errors, odfpy names. hello.py
  2. Open, read and edit existing files: Excel values, PowerPoint placeholders, lossless saving. edit_existing.py
  3. Excel, PowerPoint and pictures: one core, three formats. showcase.py
  4. Structured Word reports: sections, headers and footers, links, notes, comments, table of contents, templates. report.py
  5. Tables, floating pictures and tracked changes: merged cells, header rows, text wrapping, suggested edits, accept/reject. tables_review.py
  6. Formatting, fields and forms: run and paragraph formatting, custom styles, properties, captions and cross-references, content controls, SVG/EMF/WMF/TIFF. forms_fields.py
  7. Formatted Excel reports: cell styles, number formats, dates, column widths, frozen panes, filters, names, drop-downs. excel_report.py
  8. Tables, conditional formatting, notes and print setup: Excel tables with totals, conditional formats, comments, hyperlinks, shared strings, print setup, hidden and protected sheets. excel_dashboard.py
  9. Charts in Excel, Word and PowerPoint: column, bar, line, area, pie, doughnut and scatter charts from cell ranges or Python data, titles, axes, legends, labels, colours, combination charts with a second axis, reading charts back. charts.py
  10. Layouts, tables, shapes and notes in PowerPoint: Office's standard layouts, tables in built-in styles, shapes with fills, speaker notes, picture placeholders, reading slides, editing tables, links. slides.py

Every code block in these pages is executed by the test suite (tests/test_examples.py), so the tutorials stay accurate.
