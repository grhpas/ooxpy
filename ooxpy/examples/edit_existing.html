Tutorial 2: Open, read and edit existing files

Works on files from Excel, PowerPoint, Word, LibreOffice, openpyxl… Script: examples/edit_existing.py

If you have no files at hand, this makes two to practise on. Otherwise use your own paths below.

from oox import PresentationDocument, SpreadsheetDocument

book = SpreadsheetDocument.new("Stock")
book.append_row("Stock", ["Item", "Qty"])
book.append_row("Stock", ["Pens", 120])
book.append_row("Stock", ["Paper", 40])
book.save("stock.xlsx")
PresentationDocument.new().save("deck.pptx")

Open anything

open_document looks at the package and returns a WordprocessingDocument, SpreadsheetDocument or PresentationDocument:

from oox import open_document

book = open_document("stock.xlsx")
print(type(book).__name__, book.sheet_names)
SpreadsheetDocument ['Stock']

Read Excel values

print(book.values("Stock"))          # dense rows from A1
print(book.value("Stock", "B2"))     # one cell
print(book.cells("Stock"))           # {"A1": ..., ...} non-empty cells only
[['Item', 'Qty'], ['Pens', 120], ['Paper', 40]]
120
{'A1': 'Item', 'B1': 'Qty', 'A2': 'Pens', 'B2': 120, 'A3': 'Paper', 'B3': 40}

Shared strings (what Excel writes), inline strings, booleans, errors (CellError("#DIV/0!")) and cached formula results are all decoded. Formulas written by oox or openpyxl have no cached result until Excel saves the file, so they read as None. Pass formulas=True to get the Formula instead. Dates come back as serial numbers; convert them with oox.spreadsheet.from_excel_serial.

Change cells

from oox.spreadsheet import Formula

book.set_value("Stock", "A5", "Total")
book.set_value("Stock", "B5", Formula("SUM(B2:B3)"))
book.set_value("Stock", "C1", "Checked")   # new cell in an existing row
book.save("stock-edited.xlsx")
print(book.value("Stock", "B5", formulas=True))
Formula(expression='SUM(B2:B3)')

Rows and cells are inserted in order, and a replaced cell keeps its style (bold, number format…).

PowerPoint: layouts and placeholders

deck = open_document("deck.pptx")
print(deck.layout_names)
slide = deck.add_slide("Title and Content")      # copies the layout's placeholders
deck.set_placeholder_text(slide, "title", "Results")
deck.set_placeholder_text(slide, "body", ["Revenue up", (1, "mostly North"), "Costs flat"])
deck.save("deck-edited.pptx")
['Title Slide', 'Title and Content', 'Section Header', 'Two Content', 'Comparison', 'Title Only', 'Blank', 'Content with Caption', 'Picture with Caption', 'Title and Vertical Text', 'Vertical Title and Text']

A new deck has Office's eleven standard layouts; a deck made in PowerPoint has its own. Placeholders are found by alias ("title", "subtitle", "body"), by type ("ctrTitle", "obj") or by index (2). Text formatting comes from the layout and master, just as when you type into PowerPoint.

Word: read and append

from oox import WordprocessingDocument, teletype
from oox.ns import w

WordprocessingDocument.new().save("letter.docx")
doc = open_document("letter.docx")
doc.body.add(w.P(w.R(w.T("Appended paragraph"))))
print([teletype.extractText(p) for p in doc.getElementsByType(w.P)])
doc.save("letter-edited.docx")
['Appended paragraph']

What saving keeps

Only what you changed is rewritten. Every other part of the package, including parts you only read, is written back byte for byte. Adding one slide to PowerPoint's own template changes 3 of its 36 zip entries.

import zipfile

before, after = zipfile.ZipFile("deck.pptx"), zipfile.ZipFile("deck-edited.pptx")
print([n for n in before.namelist() if before.read(n) != after.read(n)])
['[Content_Types].xml', 'ppt/presentation.xml', 'ppt/_rels/presentation.xml.rels']
