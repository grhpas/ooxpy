Tutorial 9: Charts in Excel, Word and PowerPoint

Column, bar, line, area, pie, doughnut and scatter charts; titles, axes, legends, data labels and colours; reading charts back. Script: examples/charts.py

A chart from a cell range

from oox import SpreadsheetDocument

book = SpreadsheetDocument.new("Sales")
book.append_row("Sales", ["Region", "Q1", "Q2", "Q3"])
for row in [("North", 120, 135, 150), ("South", 95, 110, 99), ("West", 80, 84.5, 91)]:
    book.append_row("Sales", list(row))
book.add_chart("Sales", "column", "A1:D4", anchor="F2", title="Quarterly sales",
               y_title="EUR k", legend="bottom")
info = book.charts("Sales")[0]
print(info["type"], info["anchor"], [s["name"] for s in info["series"]])
print(info["series"][0]["values_ref"], info["series"][0]["values"])
column F2 ['Q1', 'Q2', 'Q3']
Sales!$B$2:$B$4 [120, 95, 80]

The range's first row names the series and its first column holds the categories. The chart refers to the cells, so it follows later edits in Excel, and it also stores their current values, so every viewer draws it straight away. The default size is 15 × 7.5 cm (width=, height= in EMU, see oox.units).

Kinds, groupings and options

book.add_chart("Sales", "pie", "A1:B4", anchor="F18", title="Q1 share", labels="percent")
book.add_chart("Sales", "line", "A1:D4", anchor="N2", series_in="rows", markers=False)
book.add_chart("Sales", "bar", "A1:D4", anchor="N18", grouping="stacked",
               colors=["2F5496", "ED7D31", "A5A5A5"])
print([c["type"] for c in book.charts("Sales")])
book.save("charts.xlsx")

All kinds take title=, legend= ("right", "bottom", "top", "left", None), labels= ("value", "percent", "category", "series"), colors=, and, except pie and doughnut, x_title=, y_title=, number_format=, gridlines=, y_min=/y_max=. series_in="rows" reads one series per row. The type names match Excel's own chart types (oox.charts.EXCEL_CHART_TYPES). oox always writes explicit colours: without them, viewers other than Office draw empty bars.

Charts in Word and PowerPoint

from oox import WordprocessingDocument

doc = WordprocessingDocument.new()
doc.add_chart("column", ["Q1", "Q2", "Q3"], {"North": [120, 135, 150], "South": [95, 110, 99]},
              title="Sales", labels="value")
doc.save("charts.docx")
print(doc.charts()[0]["series"][1]["values_ref"])

from oox import PresentationDocument
from oox.units import Inches

deck = PresentationDocument.new()
slide = deck.add_slide("Blank")
deck.add_chart(slide, "doughnut", ["Web", "Shop", "Phone"], {"Channel": [55, 30, 15]},
               Inches(1), Inches(1), Inches(5), Inches(5), labels="percent")
deck.add_chart(slide, "scatter", [1, 2, 3, 4], {"Measured": [2.1, 3.9, 6.2, 7.8]},
               Inches(6.5), Inches(1), Inches(5), Inches(5), lines=True, legend=None)
deck.save("charts.pptx")
print([c["type"] for c in deck.charts(slide)])
['doughnut', 'scatter_lines']

Here the data comes from Python: categories plus {name: values}. oox also stores it in a small workbook inside the file, which the chart refers to, so Edit Data in Word and PowerPoint opens the numbers.

Reading charts

from oox import open_document

again = open_document("charts.xlsx")
for chart in again.charts("Sales"):
    print(chart["anchor"], chart["type"], chart["title"])

charts() works on files from Excel and LibreOffice too. Each entry has the type, title, legend position, axis titles, value number format, data labels, and per series its name, values, categories, cell references and colour. For one chart part, oox.charts.chart_info does the same. Charts written by openpyxl carry no cached values; for them oox reads the values from the cells the chart refers to.

Combination charts and a second axis

book = SpreadsheetDocument.new("Prices")
book.append_row("Prices", ["Month", "Units", "Price"])
for row in [["Jan", 120, 2.5], ["Feb", 150, 2.25], ["Mar", 90, 2.75]]:
    book.append_row("Prices", row)
book.add_chart("Prices", "column", "A1:C4", kinds={"Price": "line"}, secondary=["Price"],
               y_title="Units", y2_title="EUR", y2_number_format="0.00")
chart = book.charts("Prices")[0]
print([(s["name"], s["type"], s["axis"]) for s in chart["series"]], chart["y2_title"])
[('Units', 'column', 'primary'), ('Price', 'line_markers', 'secondary')] EUR

kinds= gives series (by name, or 0-based position) another kind than the chart's; columns, lines and areas combine, bars only with bars. secondary= puts series on a second value axis at the right, with its own y2_title=, y2_number_format=, y2_min= and y2_max=. Areas are drawn behind columns and columns behind lines, and the legend lists them in that order. The same options work for Word and PowerPoint charts; oox.charts.Series takes kind= and axis= too.
